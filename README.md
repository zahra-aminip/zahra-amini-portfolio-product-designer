# Zahra Amini — Product Design Portfolio

Multi-page static portfolio, ready for GitHub Pages.

## Pages
- `index.html` — home
- `work.html` — selected work
- `about.html` — about
- `case-study-nexa.html` — Nexa case study
- `case-study-order.html` — Order & Approval case study
- `case-study-babak.html` — Babak Diemaking case study

## Adding project images
Put exported JPG/PNG/WebP files in `assets/images/`. The current case-study pages contain clearly marked image placeholders so the real screenshots can be inserted later.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
Upload the whole folder to a GitHub repository and enable GitHub Pages from Settings → Pages.
